# Simulación de Infraestructura de Teletrabajo

Proyecto final del ciclo **Técnico Superior en Administración de Sistemas Informáticos en Red (ASIR)**.  
Consiste en la simulación de una infraestructura de red orientada al teletrabajo, desplegada en un entorno virtualizado.

## Objetivos

- Implementar una infraestructura que permita el teletrabajo de forma segura y eficiente.
- Documentar y planificar el despliegue técnico de los servicios y la red.

## Tecnologías utilizadas

- **Proxmox VE** como plataforma de virtualización.
- **OPNsense** como cortafuegos y solución de red.
- **Linux (Debian)** como sistema base para servidores.
- Servicios: DNS, DHCP, VPN, FTP.
- VLANs y configuración de switches virtuales gestionables.

## Contenidos principales

- Instalación y configuración de servicios de red (DNS, DHCP, VPN, FTP).
- Segmentación de red mediante VLANs.
- Gestión de usuarios en entorno Linux con medidas básicas de seguridad.
- Documentación técnica detallada de la planificación y el despliegue.
